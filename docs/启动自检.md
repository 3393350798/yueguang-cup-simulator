# 启动自检与接入

Windows 上双击项目根目录的 `launcher.bat` 打开「月光杯 · 启动与排障」。可以启动练习、安装项目依赖、按接入方案自检、列出 COM 口或导出诊断；选择安装才会安装 Python 包。原有 `start.bat` 仍可直接启动，失败时会进入同一个排障菜单。

启动逐步检查：**启动依赖通过 → Webots 进程已启动 → 网页响应 → 本次控制器上送首个状态**。最后一项只接受本次启动的控制器记录；旧日志或只有网页响应都不能算启动完成。网页响应但最后一步超时时，先去 Webots 窗口看控制器提示，或选「导出启动与运行诊断」。超时留下 Webots 供检查，重试前请先关闭该窗口。浏览器显示在线、相机有画面、实体串口和预期回包仍要各自确认。

当仿真启动失败、相机没有图或串口没有回包时，可在菜单选「按接入方案自检」，也可双击 `scripts/check-setup.bat`。自检会要求选择「手动探索 / Python」「STM32 + OpenMV」或「STM32 + 手机串流 + 电脑视觉」。确保已安装项目依赖。

需要把问题交给负责人排查时，可单独运行 `scripts/export-diagnostics.bat`，详见[故障诊断](故障诊断.md)。

如果是实体车连接失败，可先在菜单列出 Windows 识别的 COM 口；这个操作不打开串口也不发指令。需要观察本机是否能打开、收到数据或匹配回包时，按[实车串口自检](实车串口自检.md)另行使用 `scripts/check-serial.bat`。

| 结果 | 怎么处理 |
| --- | --- |
| 失败 | 按对应行修正。常见情况是 Webots 路径错误、忘记安装 Renode、固件格式错误，或多个设备用了同一 GPIO。 |
| 提醒 | 核对具体固件配置。例如编码器只绑了 A 相时，平台不会产生这组编码反馈。 |
| 未实测 / 未启用 | 该步骤还没有观察到，或可选功能没打开。启动 Webots 后可重新检查，也可按方案在实体设备上验证。 |

默认只读项目配置和本机 HTTP。选择运行独立 Renode 探针后，会将已导入固件载入单独实例，推进 32 ms 虚拟时间，记录 PC、时钟和是否主动发出串口字节。它不会控制 Webots 小车，也不会向任何串口发送指令。短时载入通过，只说明程序可在模拟 MCU 中起步；仍需检查设备逻辑、时序和协议。

如果短时启动通过但运行没有预期动作，可进一步用[固件测试台](固件测试台.md)检查已知输入下的外设响应。

也可以在命令行使用，例如：

```powershell
scripts\check-setup.bat --route openmv --boot
scripts\check-setup.bat --route phone --panel-port 1234 --vision-port 8765
```

`--panel-port` 用于自定义 Webots 面板端口。`--vision-port` 用于覆盖本次检查的本机联调端口，配置文件照旧。如 Webots 安装在其他目录，可以在自检加 `--webots-home`，实际启动按 [README](../README.md) 设置。

在自定义端口打开整个菜单，可以用 `launcher.bat -PanelPort 1250 -WebotsHome "D:\Webots"`，菜单中的启动和自检会沿用这两项参数。

## STM32 + OpenMV

1. 在硬件窗口导入 STM32 镜像并绑定设备。OpenMV 视觉程序仍在自己的实体板上运行。
2. 在练习面板保存相机原图，用实体 OpenMV 按自己的固件能读取的格式回放，确认识别输出符合队伍协议。
3. 用练习面板的 HEX 模式把实际协议帧送给模拟 STM32；对照串口区的 RX、TX 和自己的预期。确认后再在真实硬件上核对 UART 号、波特率、TX/RX 交叉和共地。

## STM32 + 手机串流 + 电脑视觉

1. 先让电脑视觉程序读到你的手机串流。也可用相同程序从仿真的 `GET /frame.png` 获取测试帧。手机串流和本机虚拟相机是两路输入。
2. 在硬件配置开启本机联调端口，重启 Webots。自检可确认图像解码、分辨率和串口读取端点。
3. 选择固件模式并开始运行。将自己的协议帧通过面板或本机接口发送，观察波形中的实际输入、输出并核对预期。HTTP 204 只表示请求已入队；只有匹配预期的 MCU 输出，才能确认本次协议往返。
4. 在实车上用自己的无线串口替换仿真接口，重新验证配对、波特率及延迟。

固件格式和 GPIO 的详细限制见 [固件执行](固件执行.md)；图像和字节接口见 [调试与联调](调试与联调.md)。
