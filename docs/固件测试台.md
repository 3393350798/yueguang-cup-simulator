# STM32 外设测试台

小车不动时，可跳过赛道和视觉程序，先给已导入的 STM32F103C8T6 固件一组已知输入，再看虚拟 MCU 的引脚和串口输出。台架会启动独立 Renode 实例，只在本机仿真；不启动 Webots、不连接 COM 口、不烧录板卡。先运行 `setup.bat` 和 `scripts/setup-firmware.bat`，再用 `scripts/import-hardware.bat` 导入固件、保存所测外设的绑定。允许只绑定要测的一组引脚，例如只测 ADC 或 USART 时无需配置两侧电机。

双击 `scripts/firmware-bench.bat`，按提示设置通道。可按回车跳过；不填 UART 时不会自动发送任何测试帧。默认先预热 128 ms，再测试 320 ms，时间指 Renode 虚拟时间。从第一周期就应用指定的红外和距离值，兼容只在初始化时读取一次的固件；若要测试预热后才变化的输入，可在命令行加 `--inputs-after-warmup`，预热期间红外为 0、超声波无回波。编码器运动和 UART 测试帧均从测试阶段开始注入。

在 PowerShell 或命令提示符也可指定工况（示例要求这些外设已绑定）：

```text
scripts\firmware-bench.bat --ir "0=1024,1=3072" --encoder-left 64 --encoder-right -64 --sonar "front=20,left=none"
```

| 输入或输出 | 怎么看 |
| --- | --- |
| 红外 | `--ir "0=1024"` 向已绑定的 `ir0` 注入 0～4095 的 12 位输入。PA0～7、PB0～1 会同时驱动相应 ADC1 通道；其他支持的脚只有数字输入，按固件配置的阈值生成 0/1。未指定的红外输入为 0。 |
| 编码器 | `--encoder-left 64` 在测试时段均匀注入总计 64 个正向计数（四倍频后），负数表示反向。要绑齐 A、B 相。报告是台架施加的计数，固件内部计了多少可用自己的调试输出验证。 |
| 超声波 | `--sonar "front=20"` 将 `front` 对应通道设为 20 cm，有合格触发才产生模拟回波。支持 2～400 cm；设 `none` 或不填代表无回波。报告分别列出合格触发次数和回波开始次数。 |
| PWM 和方向 | 每周期末读取可用的 PWM 占空比、IN1/IN2 状态和配置方向后的驱动比例。未绑定、引脚仍为输入、当前定时器复用/模式不支持，会与已观察到的 0 区分。该占空比来自定时器或 GPIO 状态，不能替代示波器。 |
| UART | 用 `--uart-hex` 输入自己的字节；英文分号分隔的各帧从测试第一周期起逐周期注入指定的虚拟 USART。可用 `--expect-hex` 查找测试期 MCU 发送数据中的连续字节片段。匹配仅表示看到了指定序列，建议选能与回显和周期输出区分的应答。 |

退出码 0 表示取得观察结果（如指定回包则已匹配），2 表示完成测试但未看到预期片段，1 表示配置或运行失败。调试命令选项可用 `--help` 查看。若固件需要较长时间初始化，可用 `--warmup-ms` 延长预热，测试时间用 `--duration-ms` 设定，均为 `--step-ms` 的整数倍。每次启动都从镜像初始状态重新执行。

报告在项目下的 `output/firmware-bench-*/report.json`，记录虚拟时间、PC、输入设定、外围状态和 UART 计数及匹配结果。不包含固件镜像、镜像路径、报文原文或 Renode 控制台日志。台架结束后会关闭自己启动的 Renode，并清理临时副本；如需查看 TX 内容，可用 `--show-uart` 只在本机终端显示测试阶段最多 512 字节。

台架结果用于缩小排查范围。看到 PC、引脚或串口活动，只代表虚拟芯片有相应观察，不能证明应用逻辑、实际板卡接线、供电或电气时序正确。模型范围见[固件执行](固件执行.md)，实体 COM 问题使用[实车串口自检](实车串口自检.md)。
