# 实车与仿真波形对照

双击 `scripts/telemetry-compare.bat` 打开离线对照。先在 Webots 面板的「高级联调 → 调试波形」录制同一个动作，停止后点「导出 JSON」；实车一侧则用你自己的日志程序记录，整理成 CSV。这个工具不会打开串口、控制车辆、运行会员程序或上传文件。

已有队伍原始日志但列名或时间单位不一致时，先用[实车录制与联调](实车录制与联调.md)映射并生成这里需要的 CSV，同时查看视觉和串口的事件先后。

1. 选择仿真波形和实车 CSV。仿真输入支持完整「调试波形」JSON 或同格式 CSV；失败片段不作为输入。
2. 选择一种时间对齐方式，点「开始对照」。窗口会显示两侧的原始对齐时刻及共同覆盖的时长。
3. 点表中的信号看叠加曲线。蓝色是仿真，橙色是实车。可另存指标 JSON，报告不包含原始波形、文件路径、串口数据或相机画面。

| 时间对齐 | 适用情形 |
| --- | --- |
| 各自首个采样点（默认） | 两份记录以同一动作开始，或只想先预览。软件不会自动寻找动作。 |
| 手动指定时间 | 两份记录都能找到动作标记。填写各文件内该时刻的秒数；例如仿真 56.192 秒、实车 3.240 秒都代表同一次动作的开始。 |
| 同路 PWM 首次过门槛 | 两边都有同侧 PWM 且记录了动作前后。门槛为同方向的比例，例如正向 `0.20`、反向 `-0.20`。每份记录取第一次从门槛内进入门槛外的采样点，结果列出这两个原始时刻；录制一开始就在门槛外且没有下一次跨越时无法自动对齐。 |

想判断电机在同样的输入下是否起步更晚，可以在 PWM 对齐时填写同侧轮速门槛（如 `0.05 m/s`）。工具测的是各自 PWM 门槛采样点到首次观察到速度过门槛的时间，方向取 PWM 的符号。先确认两边实际输入幅值、起始状态和负载相同；这不是自动求出的通信延迟。不同采样率下请同时看报告中的采样间隔，不能据此声称亚采样周期精度。没有观察到有效跨越时留空。

## 实车 CSV 格式

用窗口中的「保存空白 CSV」生成表头；只填要比较的列。每行使用同一个采样时刻，缺测用空格或空字段，**不要填 0 代替缺测**。文件为 UTF-8、逗号分隔；可只保留需要的列。时间严格递增，建议用每次动作的本地相对时间，不能在同一文件内重复时间戳。

| 列 | 单位与约定 |
| --- | --- |
| `time_s`（必填） | 秒。如果板端是毫秒，填入前除以 1000。 |
| `pwm_left`、`pwm_right` | 有符号占空比例，−1～1；带符号的 30% 填 `0.3` 或 `-0.3`，方向与仿真轮方向一致。 |
| `speed_left_m_s`、`speed_right_m_s` | 有符号轮周速度，m/s；不使用车身速度替代。 |
| `encoder_left_rad`、`encoder_right_rad` | 累计轮角，rad；用对应轮每转计数换算：计数 × 2π / 每转计数。两边请使用同一零点约定，工具不会重置角度或猜测编码器极性。 |
| `sonar_front_mm`、`sonar_left_mm`、`sonar_right_mm`、`sonar_rear_mm` | mm，需同一安装位置与方向。仿真的自定义通道名暂不映射；超量程或无回波可在实车日志写为空。 |
| `ir0`～`ir31` | 0 为黑，1 为白，按对应传感器顺序比较；先统一 ADC 极性与量程。 |

```csv
time_s,pwm_left,speed_left_m_s,sonar_front_mm
0.000,0,0,405
0.032,0.30,0,403
0.064,0.30,0.05,
0.096,0.30,0.10,398
```

窗口和报告只比较同名通道的重叠时段。以实车采样时刻查仿真值：PWM 保持上一点，其他通道在相邻有效采样间直线插值；不外推，不跨越缺测行或超过约三个仿真典型采样间隔的断点。平均偏差是实车减仿真，另给 MAE、RMSE 和有效配对点数；少于两个配对点不给误差结论。误差按采样点计，不按时间加权。两边时钟速率不同或动作不一致时，请结合原始日志检查；工具只对齐一个时间点。

也可以在项目目录运行：

```powershell
scripts\telemetry-compare.bat template output\实车模板.csv
scripts\telemetry-compare.bat normalize 录制.json output\仿真通道.csv
scripts\telemetry-compare.bat compare 录制.json 实车.csv --align manual --sim-t 56.192 --real-t 3.240 --report output\对照.json
scripts\telemetry-compare.bat compare 录制.json 实车.csv --align pwm --side left --pwm-threshold 0.20 --speed-threshold 0.05
```

手动或会员 Python 模式的波形可能没有 PWM；此时仍可用手动对齐比较轮速、编码器、超声波和红外。本功能不要求固定的队伍串口协议；从实际 STM32、OpenMV 或电脑程序导出 CSV 需各队按自己的接法完成。实体记录和接线应该单独验证。
