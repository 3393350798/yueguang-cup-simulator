# 夹爪测试台

夹爪测试台使用独立 Webots 场景，对当前虚拟车的夹爪做原地取放测试。它会复制车体与模型到项目内的 `output/gripper-bench-*`，制动两侧车轮，不加载会员算法或固件。每轮依次张开夹爪、合爪、抬升、观察持握、释放并等待物块落稳。

## 启动

先完成项目安装和 Webots 安装，再双击 `scripts/gripper-bench.bat`。默认打开窗口；也可从命令提示符运行参数化组合：

```bat
scripts\gripper-bench.bat --y-mm 0,-8,8 --friction 0,0.85 --mass-g 40,60
```

默认测试左侧 8 mm、居中和右侧 8 mm 三个位置，前后偏差、偏角和初始倾角为零，夹持摩擦及物块质量沿用当前模型。支持前后/左右偏移（`--x-mm`、`--y-mm`）、平面偏角（`--yaw-deg`）、初始倾角（`--tilt-deg`）、夹持摩擦（`--friction`）、物块质量（`--mass-g`），以及 `--repeat` 重复次数。输入多个逗号分隔的值会测试每种组合，最多 64 轮。偏移相对抓取中心，正 X 向车头、正 Y 向小车左侧；角度单位是度，摩擦系数无量纲，质量单位是克。赛事物块轮廓绕竖轴对称，改变平面偏角通常不会明显改变抓取结果。物块放入后先在地面自由运动，报告记录合爪前的实际倾角和位移。

抓取中心默认取参数夹爪两指间的中心；导入 URDF 时，以所绑定夹持面连杆的重心估算，可用「抓取中心」或 `--center-x-mm`、`--center-y-mm` 修正。导入模型需要已配置开合关节、升降关节和至少两个带碰撞几何的夹持面。可勾选「显示 Webots 场景」按实时速度查看；停止测试或关闭窗口会结束本次台架进程。

## 报告

结果目录包含 `report.json`、`report.csv`、本次车模副本和 Webots 日志。JSON 附车模和模型依赖的摘要哈希，便于区分不同设计。`提起`表示至少两处夹持面持续接触且物块离地；`掉落`表示曾持稳而后在主动释放前失去持握；`最高离地量`按物块几何体最低点计算。持握到主动释放后，物块在地面附近、速度与角速度低且不接触爪指，连续满足 200 ms 才记为`落稳`。`落点偏差`以本轮物块预设位置（已含偏移）为基准，只有落稳后才填写，并记录物块是否直立。报告还保留合爪前的位移、合爪过程中推移的距离和本轮末的位置偏差，即使未抓起也便于定位原因。

这些工况用于比较设计；赛事计分和容差以赛题为准。提起成功后仍需在实体车上检查电机出力、夹爪表面、装配间隙及行驶时的持握表现。分享结果时可单独发送 JSON/CSV；完整目录还含模型副本及本地日志，应留在本机。报告不含会员代码、串口数据、图像或录像。
