# 自定义小车

关闭 Webots，双击 `scripts/import-hardware.bat`。在“机械模型与驱动”页修改尺寸，在“传感器摆位”页设置红外、超声波及相机，在“F103 引脚图”页选管脚和设备。也可用 `scripts/configure.bat` 直接编辑 `simulator/robot.json`。保存后运行 `start.bat`，面板中“当前小车硬件”会显示生效的设置。

当前采用两轮差速加后支撑轮。配置影响实际物理模型、传感器设备、图像尺寸、轮速换算、夹爪运动和停车判定。修改文件后需重新启动，面板的「重载算法」用于重载会员程序。

## 坐标和单位

长度使用 mm，质量使用 kg，速度使用 m/s，扭矩使用 N·m，角度使用度，时间依字段名标注。传感器的 `position_mm` 是相对安装原点的 `[前后, 左右, 上下]`，前、左、上为正方向。参数车模的原点在底盘盒体中心，URDF 装配体采用 URDF 根坐标。

底盘中心离地高度为 `clearance_mm + height_mm / 2`。默认是 32 mm，因此红外位置 `[62, 0, -20]` 表示位于底盘中心前方 62 mm、离地约 12 mm。

## 参数

| 分组 | 字段与作用 |
| --- | --- |
| `name` | 车模名称，显示在面板中 |
| `step_ms` | 车体与固件反馈周期；可选 4、8、16、32 ms，默认 32 ms。步长越短，反馈更新越频繁，运行开销也可能更高 |
| `vision_link_port` | 本机外部视觉接口端口，`0` 关闭，使用方法见 [调试与联调](调试与联调.md) |
| `body` | `length_mm` 长、`width_mm` 宽、`height_mm` 高、`clearance_mm` 底面离地间隙、`mass_kg` 底盘质量 |
| `body.center_of_mass_mm` | 参数车模底盘重心；坐标前、左、上为正。默认样车为 `[-18.35, 0, 0]`。夹爪质量与位置由物理引擎另计，改爪时底盘重心不会自动移动 |
| `wheels` | `radius_mm` 半径、`width_mm` 轮宽、`track_mm` 左右轮中心间距、`mass_kg` 单轮质量 |
| `wheels` | `max_speed_m_s` 轮缘速度上限、`max_torque_nm` 单轮最大扭矩、`response_s` 简化响应时间常数 |
| `caster` | `x_mm` 后支撑轮前后位置、`radius_mm` 支撑轮半径；支撑轮位于车体中线 |
| `camera` | `position_mm` 位置、`pitch_deg` 向下俯角、`yaw_deg` 水平朝向（正值向左）、`width`/`height` 图像像素尺寸、`fov_deg` 视场角 |
| `ir.positions_mm` | 每个元素代表一路向下的红外；列表的数量和顺序直接对应会员输入 `sensors['ir']` |
| `sonar` | `range_mm` 测距量程、`aperture_deg` 测距张角 |
| `sonar.sensors` | 每项的 `name` 是接口名称，`position_mm` 是安装位置，`yaw_deg` 为水平朝向：0 前、90 左、-90 右、180 后 |
| `gripper` | `reach_mm` 爪指中心距原点向前距离、`opening_mm` 初始内间距、`closed_gap_mm` 合拢后的最小内间距、`finger_length_mm`／`finger_thickness_mm`／`finger_height_mm` 爪指尺寸 |
| `gripper` | `jaw_center_height_mm` 降下时爪指中心离地高度、`lift_travel_mm` 升降行程、`jaw_speed_mm_s`／`lift_speed_mm_s` 关节速度上限、`jaw_force_n`／`lift_force_n` 单个关节推力上限、`finger_mass_kg`／`carriage_mass_kg` 部件质量、`friction` 爪指与物块摩擦系数 |
| `block` | `mass_kg` 物块质量（默认暂设 0.04 kg）、`floor_friction` 物块与地面摩擦系数；比赛轮廓保持原尺寸 |

添加或删除红外位置、超声波传感器条目即可改变数量。超声波名称使用互不重复的英文标识，如 `front`、`left`、`right`、`rear`；会员从 `sensors['sonar'][名称]` 读取，面板会显示全部已配置设备。

默认摄像头为 320×240。更改为其他尺寸后，`vision()` 接收到的数组大小随之改变，保存的 PNG 也使用新尺寸。代码可通过 `image_bgr.shape` 获取实际大小。

红外采用简化反射模型；每个设备根据安装高度生成相应距离查表。轮速输出仍为目标线速度，`response_s` 表示简化执行器响应。参数夹爪使用 Webots 的碰撞体、指端和升降关节，合拢后靠接触和摩擦夹住物块；可通过调整参数观察夹不中、滑落和翻倒。关节和表面参数建议从实际机构测量。

启用夹爪时，Webots 用 4 ms 物理子步计算接触，会员程序和 MCU 仍以所选 `step_ms` 同步。默认爪指尺寸为 40 × 7 × 9 mm，开口 56 mm，合拢最小间距 24 mm，升降行程 45 mm。若已导入完整 URDF，可在硬件窗口选择它自己的活动关节与夹持面。

## 模型关系

轮距应能容纳底盘，红外应位于地面上方，支撑轮位置应能支撑车体。摄像头和传感器安装位置会随底盘尺寸改变相对离地高度。小车的整体尺寸由底盘、车轮和夹爪共同构成，会员可结合比赛尺寸限制设置。

`scripts/import-hardware.bat` 可导入 URDF 装配体或 STEP/STL/OBJ 底盘，并将模型与车轮映射写入 `simulator/robot.json` 的 `model`。安装坐标及导出方法见 [导入自己的硬件](导入自己的硬件.md)。STM32F103C8T6 程序可通过 Renode 在电脑中执行，配置方法见 [固件执行](固件执行.md)；连接真实 STM32、OpenMV 和无线串口需结合队伍设备适配。
