# 导入车模后的装配体检

导入底盘或 URDF 装配、设置车轮和传感器位置后，双击软件目录下的 `scripts/assembly-check.bat`，点击「开始体检」。先运行过 `setup.bat`。工具检查当前工程中已保存的车模，在独立的 Webots 空场运行；练习场景和原配置不变。你也可以勾选「显示 Webots 场景」，观察单轮和夹爪动作。

| 检查 | 会看到什么 |
| --- | --- |
| 左右轮 | 一次只给一个轮低速正向指令。记录车体前后位移、偏航角和编码器原始增量。车前由模型的 X 正向定义，左轮单独向前应使车向右偏，右轮应使车向左偏。后移优先查正向符号；前移但偏航方向颠倒优先查左右轮绑定。没有位移时还要查轮胎接地和碰撞几何。 |
| 红外 | 车不动，分别读取均匀黑、白参考地面的原始值。对比不足时核对离地高度、传感器是否被零件挡住，以及模型的地面响应；对比不足本身不能区分这些原因。 |
| 相机 | 同一个 100 × 100 mm 洋红标靶依次放在正前方、左 110 mm、右 110 mm，中心离地 75 mm，默认距车体原点 350 mm。报告分别标出三个位置的可见像素与范围，另存空景和三张原图。中央看不见但两侧可见时，可检查图中夹爪、相机支架或车身的遮挡。默认车的橙色夹爪立柱就可能挡住中央标靶。 |
| 夹爪 | 低位开合，若配置了升降则再测高位开合和返回低位，对照各阶段目标与位置反馈。体检场景开启车内碰撞并记录高于地面的接触；能定位到夹爪相关连杆时标出，否则只记录发生接触的阶段。 |

「符合」只指当前体检项目达到参考条件。「需核对」表示看到了需要检查的现象；「未观测」表示未配置、缺少反馈或行程未完整走过。没有观察到车内接触，只覆盖本次动作及 Webots 能检测的碰撞体；只导入外观网格的车仍使用简化的底盘包围盒。体检不能替代 CAD 全行程检查、实物装配验收或抓取测试。要比较夹持力、滑落及抓取容错，请用[夹爪测试台](夹爪测试台.md)。

完成后点击「打开结果目录」看报告和图片。文件保存在本地 `output/assembly-check-*/`，不会上传。工具只复制必要的车模数据到临时场景，不执行队伍算法、不读取固件或接通串口。日志和相机图片可以包含队伍自定义车模信息，按需自行选取分享。

命令行也可运行，端口默认自动分配；已有窗口占用指定端口时会提示换一个。

```powershell
.\scripts\assembly-check.bat --target-mm 350
.\scripts\assembly-check.bat --show --port 1261
```
