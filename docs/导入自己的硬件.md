# 导入自己的硬件

关闭 Webots，双击 `import-hardware.bat`，在窗口中导入文件并保存，再运行 `start.bat`。普通尺寸及传感器布置仍使用 `configure.bat` 编辑 `robot.json`。

导入资料保存在本机 `hardware/imported/`，自动生成的 URDF 转换结果在 `protos/imported/`，两个目录均已加入 Git 忽略规则。模型重新生成后的 `robot.json`、`board.json`、`scene.json`、`scene.js` 和世界文件会反映个人配置；分享整套项目时，请自行选择希望分享的内容。

## SolidWorks装配体

在 SolidWorks 中通过 [URDF导出插件](https://github.com/ros/solidworks_urdf_exporter)导出模型，将一个 `.urdf` 和所引用的网格一起打包为 ZIP，再在导入窗口选择“导入 URDF / ZIP 装配包”。也可以直接选择本机 URDF。插件需与所用 SolidWorks 版本兼容。

原始 `.SLDASM` 及 `.SLDPRT` 需先在 SolidWorks 中导出。SolidWorks 的 Pack and Go 适合收集原始装配及引用零件；原始装配压缩包仍需完成 URDF 或 STEP 转换。导入窗口接受包含 URDF 的 ZIP。

1. 在关节列表中找到左右轮，分别绑定。
2. 填写根坐标原点的离地高度、轮半径及轮距。URDF 的长度单位为 m，窗口内尺寸单位为 mm。
3. 左右轮正向系数填 `1,1`；若某轮正转方向与前进方向相反，将对应系数改为 `-1`。
4. 底盘长、宽、高用于停车轮廓显示与判定，按车体实际占用范围填写。传感器位置由 `robot.json` 配置，相对 URDF 根坐标。
5. 保存并启动，在面板先进行手动探索。额外旋转/移动关节显示在“装配体关节”卡片中。

坐标统一为 X前、Y左、Z上；根坐标的XY原点应位于左右轮轴线中点。红外射线需朝向地面且没有零件遮挡。质量、重心、惯量与碰撞几何来自URDF；这些数据会影响车体是否稳定，以及传感器的实际离地高度。

支持 fixed、continuous、revolute、prismatic 关节。当前练习接口仍以两轮差速驱动为基础；URDF应是树形装配。装配闭环约束、mimic联动及真实接触抓取需要专门适配。取放继续使用 `robot.json` 的简化夹持参考点，关节运动可以独立调试。

导入过程将引用的 STL/OBJ/DAE 等网格转换成独立 STL，保留几何及URDF材质颜色，网格原始贴图不随转换保留。模型含多个URDF时，请解压并选择目标URDF。

项目附有 `hardware/examples/differential.urdf`，可直接导入体验：左轮 `drive_left`、右轮 `drive_right`、原点高度32 mm、轮半径27 mm、轮距125 mm，正向系数 `1,1`。额外关节名为 `tool_hinge`。

## STEP、STL与OBJ底盘

单体底盘可以从 SolidWorks 另存为 STEP，或导出 STL/OBJ，再选择“导入 STEP / STL / OBJ 底盘”。需要STEP时先运行 `setup-cad.bat`；转换组件约需下载130 MB及其依赖，具体取决于Python版本。

STL/OBJ需在窗口选择输入单位，STEP转换统一为mm。几何导入后会居中并自动填写底盘包围盒尺寸，车轮、后支撑轮与简化夹爪沿用参数车模。此入口适合单体底盘；包含整套车轮和机构的模型应导出URDF，以保留各部件运动关系。碰撞采用填写的底盘包围盒。

## 嘉立创EDA与STM32F103C8T6

在嘉立创EDA中导出 **PADS 网表**（专业版选择PADS 9.5），然后选择“导入 PADS 9.5 网表”。[标准版官方说明](https://docs.easyeda.com/cn/Schematic/Export-NetList/index.html)与[专业版官方说明](https://prodocs.easyeda.com/cn/schematic/export-netlist/)均列出PADS格式。窗口会列出器件、网络以及 `U1.10` 这类“器件编号.封装引脚”。

选择MCU器件编号，并在接线文本框逐行填写 `设备=器件.引脚`，例如 `left_pwm=U1.10`。器件编号和引脚必须按自己的原理图填写；同一封装引脚采用哪个GPIO/定时器复用功能，由固件配置决定。

设备名称：`left_pwm`、`left_in1`、`left_in2`、`right_pwm`、`right_in1`、`right_in2`、`encoder_left_a`、`encoder_left_b`、`encoder_right_a`、`encoder_right_b`、`ir0`等、`sonar_front_trig`、`sonar_front_echo`、`gripper_close`。接线也可直接填`PA0`等GPIO名。视觉串口在固件页选择USART端口。

`hardware/examples/f103-connections.net` 是接线格式示例。它展示文件结构，会员根据自己的线路配置实际引脚。

板卡外形可从EDA导出STEP，再选择“导入板卡 STEP / STL”，填写相对根坐标的安装位置。板卡模型用于显示安装外观，质量需计入车体/URDF相应质量参数。

v0.4.0增加Renode固件执行，操作与外设范围见 [固件执行](固件执行.md)。原生 `.epro` 工程需先导出网表和模型；Keil/CubeIDE工程先在对应IDE编译，再导入ELF/AXF/HEX/BIN。网表保存连接关系，器件行为由仿真模型定义。

## 命令行入口

Linux/macOS可在已激活的Python环境中运行 `python tools/hardware_editor.py`。文件转换也可单独运行：

```sh
python tools/hardware_import.py urdf path/to/assembly.zip
python tools/hardware_import.py mesh path/to/chassis.step
python tools/hardware_import.py mesh path/to/chassis.stl --unit mm
python tools/hardware_import.py netlist path/to/board.net
```

命令行输出导入结果；将其按窗口生成的结构填入配置后，重新生成场景。返回参数车模可在窗口选择“使用参数车模”并保存，原有尺寸和传感器设置会保留。
