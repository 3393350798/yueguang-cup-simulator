# 本轮求助包

完成一轮记录后，到「练习结果」点击该轮旁的「导出本轮求助包」。刷新或重开后，在「练习结果」的「本机练习历史」下展开批次，再找到对应轮次。求助包入口适用于本机轮次。[本机练习历史说明](分赛段练习.md#本机练习历史)

窗口会显示本轮工况、练习判定和将要生成的文件清单。展开预览可检查具体 JSON。点击「在本机生成 ZIP」后，浏览器只在本机生成 `moonlight-round-support.zip`，不会上传。确认内容合适后，再由队员自行发送给负责人。

基础包包含 `README.txt` 和 `round.json`，记录项目版本、场地/赛段/模式、奇偶组别、物块颜色、车辆参数摘要、扰动配置和练习结果。它不包含完整组号、队名或方案标签、电脑用户名、项目路径、相机图像、会员代码或固件、错误原文以及原始串口字节。

固定工况也会附上本轮[定时故障](故障工况回归.md)的窗口和执行摘要，例如窗口有没有运行、多少字节受影响、最早观察到的异常位置。该摘要不包含串口内容或车模文件。

可选项：

- **本轮失败回放**：默认关闭。仅当浏览器仍保有与该轮场地、赛段、颜色和仿真周期匹配的失败片段时才可选。片段可能包含片段生成时间、车体与物块位置、传感器及夹爪采样；不含相机图像或串口原文。本机历史附带的片段可能提前结束，窗口会注明。片段缺失或到达存储上限后，仍可下载基础求助包。历史使用的工程标识、关联键和方案标签均不随求助包分享。
- **Windows 诊断 ZIP 或 `diagnostics.json`**：默认不添加。工具会在本地读取并只保留有限的版本、已知事件代码、数值状态和环境提示，不保留原始错误文字、路径、用户标识或日志内容。该摘要被标记为队员另行选择的上下文，可能来自其他运行，不能据此断定事件发生在本轮。

收到求助包后，先读 `round.json` 的 `scenario`、`result` 和 `round_diagnostics`，把固件/会员程序异常与未完成的赛段动作区分开。若有 `failure-replay.json`，解压后在相同场地的面板中进入「练习结果 → 失败回放」，点击「打开失败片段」。补充摘要用来辅助排查启动或串口环境。练习结果不代表正式比赛计分。
