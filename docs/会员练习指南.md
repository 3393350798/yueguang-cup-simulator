# 会员使用指南

## 打开与重置

完成 README 中的安装步骤后运行 `start.bat`。在面板修改组号与物块颜色，再点击「重置场景」。Webots 仿真时间持续推进，面板的「开始运行」和「暂停 / 停车」控制车辆及会员算法。

调整小车尺寸与传感器时，关闭 Webots，双击 `configure.bat` 编辑 `robot.json`，再重新启动。字段与安装坐标见 [自定义小车](自定义小车.md)。

## 手动操作

按住方向按钮驾驶，松开停车。车头的橙色结构代表夹爪；接近物块后点击「夹取」，到放置位置后点击「释放」。面板记录抓取状态和放置圈中心偏差。

也可在 Webots 画面中使用 W/A/S/D，E 夹取或释放，空格停车。

点击「放到超声波区域入口」会将小车放到通道右侧入口、车头朝左，便于查看无线路段的原始测距数据。该按钮只改变初始位置。

## 图片保存

点击「保存原图」，项目 `output/` 目录会生成 PNG，尺寸与 `robot.json` 中的摄像头分辨率一致，默认 320×240。它可以由电脑上的视觉程序读取，也可以复制到真实 OpenMV 板卡中，按固件支持的格式加载。摄像头画面包含标签、物块、地面色圈和其他环境内容。

## 接入自己的程序

打开 `controllers/moonlight/member_algorithm.py`，实现 `vision()` 与 `step()`。保存后选择「会员算法」，点击「重载算法」再开始运行。输入、输出和单位见 [会员接口](算法接口.md)。

## 任务状态

偶数组号的目标为地图下排，奇数为上排，目标圈颜色与物块一致。面板显示位置、中心偏差及接触记录。

车轮与支撑点进入终点内框、连续静止 3 秒后显示停稳；底盘投影位于内框内、角度偏差不超过 10° 时显示摆正。场景采用练习判据，赛事精准计分以统一规定为准。
