# STM32F103C8T6 固件执行

想单独检查程序的红外、编码器、超声波或串口响应时，可先用[固件测试台](固件测试台.md)，无需驾驶 Webots 小车。

固件模式由 Renode 执行 Cortex-M3 指令，Webots 提供车轮运动、地面红外、超声波距离和摄像头。程序保留在本机，控制和视觉由会员自行编写。

## 从已编译固件开始

1. 安装好项目的 Python 环境与 Webots 后，运行 `scripts/setup-firmware.bat`。脚本从 Renode 官方下载约107 MB的 Windows 1.17.0 portable，解压到 `.local/renode/`。
2. 关闭 Webots，运行 `scripts/import-hardware.bat`。在“固件执行”页导入自己的 `.elf`、`.axf`、`.hex` 或 `.bin`；Keil/CubeIDE 源工程先在对应 IDE 中编译。AXF 使用 ELF 加载器，需为 ELF 格式。
3. 在“嘉立创EDA”页填写设备与 MCU 管脚。可以导入网表后使用 `left_pwm=U1.10`，也可以直接填 `left_pwm=PA0`。`U1.10` 按 STM32F103C8T6 的 LQFP48 第10脚解释，MCU编号须选为U1。
4. 在固件页填写每个车轮转一圈的编码器计数，采用四倍频后的计数，包含电机减速比。根据电机安装方向填写 `1,1`、`1,-1` 等正向系数。
5. 保存，启动 `start.bat`，选择“STM32固件 · Renode”，点击“开始运行”。首次加载需等待数秒至数十秒。面板显示 PC、MCU虚拟时间、PWM和串口输出。

ELF和HEX使用文件内的地址。BIN默认加载到 `0x08000000`，首8字节应为初始栈指针和复位入口；带偏移的应用镜像需要填写实际加载地址，并在程序中正确设置向量表。Flash为64 KiB，SRAM为20 KiB。

Renode可通过界面选择执行文件，或设置 `RENODE` 环境变量。Linux/macOS需自行安装 Renode 1.17.0，并将执行文件路径填入 `simulator/firmware.json`；跨系统入口尚待对应系统运行验证。

## 接线与器件

| 设备名 | 行为与固件配置 |
| --- | --- |
| `left_pwm` / `right_pwm` | TIM1～4的普通CH1～4，PWM1或PWM2；兼容默认映射和C8引出管脚上的TIM2/TIM3部分重映射。GPIO须配置为复用推挽/开漏输出，开启通道；TIM1还需MOE。普通GPIO输出可作0%/100%使能。 |
| `left_in1` / `left_in2` | 双方向输入：1/0正转，0/1反转，相同电平为零目标速度。 |
| `right_in1` / `right_in2` | 右电机方向，规则同左侧。每个电机需填PWM及两个方向脚。 |
| `encoder_left_a` / `encoder_left_b` | 左轮AB相，按实际转角产生均匀分布的正交边沿。可接定时器编码器模式或GPIO/EXTI计数；交换AB可改变反馈方向。 |
| `encoder_right_a` / `encoder_right_b` | 右轮AB相，规则同左侧。 |
| `ir0`、`ir1`… | 顺序对应 `simulator/robot.json` 的红外。GPIO 输入黑 0 白 1，阈值默认 0.5；绑定 PA0～7/PB0～1 时同时映射到 ADC1 通道 0～9，黑 0、白 4095。ADC1 可轮询或使用规则组扫描和 DMA1 通道 1。 |
| `sonar_front_trig` / `sonar_front_echo` | HC-SR04式触发/回波。高电平约10 µs以上的有效触发后，延迟100 µs产生回波，高电平宽度为 `2×距离/343 m/s`。2 cm～4 m有效；超出范围无回波。 |
| `sonar_left_trig/echo`、`sonar_right_trig/echo` | 同上，名称对应车模中的left/right传感器。自定义传感器可按同样命名。 |
| `gripper_close` | 可选 GPIO：1 设置物理夹爪的合拢位置，0 设置张开位置。夹持取决于接触、行程、夹力和摩擦。 |
| `gripper_lift` | 可选 GPIO：1 抬升夹爪，0 降下；机械配置需已绑定升降关节。 |

TIM1～4使用72 MHz输入时钟。TIM2的两组部分重映射、TIM3的PB4/PB5部分重映射由固件的AFIO_MAPR选择；PA15/PB3/PB4在实板上还需要按需求释放JTAG引脚。重映射到C8未引出管脚的功能无法接线。模型对Renode 1.17定时器作了小范围扩展，使编码器正转溢出、反转过零能按ARR回绕。

接线配置示意如下，所有实际管脚须与自己的固件一致；同一脚应只承担一种器件信号。

```text
left_pwm=PA0
left_in1=PB0
left_in2=PB1
right_pwm=PA1
right_in1=PB2
right_in2=PB3
encoder_left_a=PA6
encoder_left_b=PA7
encoder_right_a=PB6
encoder_right_b=PB7
ir0=PA4
sonar_front_trig=PB10
sonar_front_echo=PB11
```

## 串口与电脑视觉

在固件页选择 `usart1`、`usart2` 或 `usart3`。面板可发送 UTF-8 文本并追加换行，也可按十六进制发送原始字节。协议由会员自己定义。串口注入直接连接所选 USART 的设备模型；TX/RX 引脚复用与无线模块需在实体电路上验证。

固件模式每约 192 ms 仿真时间调用一次会员程序的 `vision(image_bgr)`。会员可以在函数中处理虚拟相机图像，然后将自己协议编码得到的文本或 `bytes` 返回给 MCU：

```python
return {'uart_tx': message}
```

`message` 由自己的视觉程序生成；可以先在面板串口栏手工发送相同协议，检查固件收包。固件模式的电机由 MCU 输出驱动，Python 中的 `step()` 在这个模式下不调用。电脑端也可使用[本机联调接口](调试与联调.md)读取模拟相机图像和收发原始串口数据。OpenMV 板卡代码需要在实体设备上运行或另行适配其运行环境。

USART1、USART2、USART3 支持轮询、中断和 DMA 收发。USART1 使用 72 MHz 外设时钟，USART2/3 使用 36 MHz；DMA1 的发送/接收通道分别为 4/5、7/6、2/3。发送 DMA 按寄存器配置的字符时长逐字节推进；输入在仿真周期边界排队注入。波特率匹配、引脚电平和无线链路行为仍应结合实体设备验证。

## 时间、控制与模型范围

在 `simulator/robot.json` 中可将 `step_ms` 设为 4、8、16 或 32 ms，默认 32 ms；修改后重新启动场景。每个周期，Webots 将传感器数据交给 MCU，Renode 执行相同长度的虚拟时间，读取周期末的 PWM 和方向，驱动下一周期的车轮。编码器把上一周期的实际转角增量转换为按时间分布的边沿，因此反馈仍有一个采样周期的延迟。较短的周期适合观察反馈变化，但会增加桥接开销。

“暂停”冻结MCU虚拟时间并让小车减速停车；“开始”继续。“重置场景”同时关闭旧MCU实例，下次开始从复位入口运行。“重载程序”重新读取固件与Python视觉程序，需再次点击开始。手动驾驶按钮会切换回手动模式。

CPU采用可配置的指令率，默认8 MIPS，填写正整数，用于指令执行与虚拟时间换算；SysTick及TIM输入固定为72 MHz。RCC配置寄存器提供就绪位和时钟切换状态，未建立可变时钟树。请使用72 MHz外设时钟的固件配置，通过SysTick/定时器计时。依赖CPU空循环次数的延时、动态变频和逐周期性能测量需要实板验证。紧密轮询和高PWM频率可能明显慢于真实时间，可调低虚拟指令率加快练习；调整后应重新核对程序中依赖指令耗时的行为。

PWM按周期末的定时器配置折算为占空比，乘以车模的 `max_speed_m_s` 得到电机目标，再使用 `response_s` 的一阶响应；Webots编码器反映轮地接触后的实际运动。可以练习收包、定时、反馈方向和速度环逻辑。电机电压、电流、反电动势、死区和精确PID参数需要结合真实驱动器及电机标定。互补PWM、复杂制动/再生和舵机脉宽模型需另行适配。

ADC1 模拟 12 位规则转换的软件启动、扫描、连续模式、EOC 中断和 DMA；校准立即完成，每次转换使用固定约 100 µs，采样时间寄存器和分频设置不改变该时长。注入组、外部触发和模拟看门狗需要另行适配。FLASH 控制区只提供初始化配置读写，USB 和 I2C/SPI 外部器件需要相应模型。

在 Renode 1.17.0 中实际运行了基于 [STM32F1 HAL v1.1.10](https://github.com/STMicroelectronics/stm32f1xx-hal-driver/tree/v1.1.10) 编译的外设样件，覆盖 72 MHz 时钟初始化、SysTick、TIM2 PWM、TIM3 编码器、双通道 ADC 循环 DMA 及回调、USART1 轮询发送、接收中断及双向 DMA 回调。另用 STM32F10x 标准外设库 3.5.0 样件验证 72 MHz 时钟初始化、PWM、ADC 校准与单通道轮询、ADC 转换完成中断、USART1 发送。兼容范围取决于会员固件实际使用的外设和时序；这些样件均在仿真环境中运行，实体板卡仍需实测。

## 本机资料

固件复制到 `simulator/hardware/imported/firmware-*/`，该目录已忽略。`.local/`保存运行时；每次执行在系统临时目录 `moonlight-fw-*` 下保留镜像副本和 `renode.log`，便于定位加载错误，这些也只在本机。配置中的本地文件路径会保存在 `simulator/firmware.json`，共享项目前请确认希望分享的资料。
