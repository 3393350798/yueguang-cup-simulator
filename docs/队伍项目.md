# 队伍项目包

在 Windows 中运行 `scripts/team-project.bat`。准备导出或导入前，先保存硬件配置并关闭正在运行的 Webots。Linux 可在虚拟环境中直接运行 `simulator/tools/team_project.py`（需要 Tk）。

1. **导出项目包**：将当前车模、板卡和固件配置、会员 Python 程序，以及配置所引用的模型、网表和固件保存为 `*.moonlight.zip`。
2. **导入到新目录**：选择队伍 ZIP 和目标上级目录。工具使用 ZIP 的名称新建独立项目；同名目录存在时可改 ZIP 名或换个位置。原项目可继续使用。
3. 在新项目中运行 `setup.bat`，再运行 `start.bat`。如需运行 STM32 固件，可在硬件配置的固件页选择本机 Renode；未安装时运行 `scripts/setup-firmware.bat`。

项目包使用硬件窗口导入后的 STL、规范化 URDF 和 PADS 网表。运行时重新生成赛场和 PROTO，Renode 路径留空。旧导入版本、录制、原始 CAD、原始 EDA 工程、运行时安装包及项目内部笔记各自在原位置保留。拆分到其他模块的 Python 源码或额外依赖应由队伍另行管理。

ZIP 含队伍算法和固件，请在需要共享的队员之间传递。运行导入项目的会员程序前确认信任发送者；会员程序在本机以 Python 执行。包格式版本为 1，解压上限 512 MiB。
