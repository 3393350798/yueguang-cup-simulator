# 会员接口

编辑 `controllers/moonlight/member_algorithm.py` 中的 `Algorithm` 类，保存后在面板选择「会员算法」，点击「重载算法」与「开始运行」。空白模板返回零轮速。

## 图像

`vision(image_bgr)` 接收 320×240、BGR 通道顺序的 `numpy.ndarray`。每个控制周期调用一次；返回值通过 `sensors['vision']` 交给 `step()`。面板显示原始摄像头图像，识别程序由会员填写。

## 传感器

`step(sensors, dt)` 每个运行周期调用，`dt` 为 0.032 秒。

| 字段 | 格式与单位 |
| --- | --- |
| `ir` | 长度 7，按车体左到右；黑线接近 0，白地接近 1 |
| `sonar` | `front` / `left` / `right`，单位 m，上限 1.5 m |
| `encoder` | `left` / `right`，累计车轮转角 rad |
| `speed` | `left` / `right`，由编码器采样得到的轮缘速度 m/s |
| `carrying` | 夹爪是否夹持物块 |
| `vision` | 自己的 `vision()` 返回值 |

暂停时停止调用会员算法；重载会重建 `Algorithm` 对象，其中的状态重新初始化。

## 输出

`step()` 返回一个字典：

| 字段 | 含义 |
| --- | --- |
| `left` | 左轮目标线速度，m/s，范围 -0.25～0.25 |
| `right` | 右轮目标线速度，m/s，范围 -0.25～0.25 |
| `gripper` | 可选，`grab` 夹取、`release` 释放 |

正轮速表示向前。底盘局部 +X 为车头，+Y 为左侧；世界坐标采用 ENU、Z 向上。桥接层用时间常数 0.12 s 的一阶响应改变电机目标转速，实际编码器继续反映轮地接触与碰撞影响。

夹爪参考点位于车体中心前方 120 mm；与物块中心的水平距离小于 50 mm 时允许夹取。该机构为简化取放模型。

场景真值用于平台绘图和任务判定。会员接口提供图像与传感器数据，控制和识别程序由会员自行编写。
