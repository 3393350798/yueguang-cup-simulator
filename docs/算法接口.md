# 会员接口

编辑 `controllers/moonlight/member_algorithm.py` 中的 `Algorithm` 类，保存后在面板选择「会员算法」，点击「重载算法」与「开始运行」。空白模板返回零轮速。

## 图像

`vision(image_bgr)` 接收 BGR 通道顺序的 `numpy.ndarray`。尺寸由 `robot.json` 决定，默认 320×240，数组形状为 `(高, 宽, 3)`。每个控制周期调用一次；返回值通过 `sensors['vision']` 交给 `step()`。面板显示原始摄像头图像，识别程序由会员填写。

## 传感器

`step(sensors, dt)` 每个运行周期调用，`dt` 为 0.032 秒。

| 字段 | 格式与单位 |
| --- | --- |
| `ir` | 按 `robot.json` 中红外位置列表的顺序排列；黑线接近 0，白地接近 1 |
| `sonar` | 按配置名称索引，默认 `front` / `left` / `right`；单位 m，量程由配置决定 |
| `encoder` | `left` / `right`，累计车轮转角 rad |
| `speed` | `left` / `right`，由编码器采样得到的轮缘速度 m/s |
| `carrying` | 夹爪是否夹持物块 |
| `vision` | 自己的 `vision()` 返回值 |
| `joints` | 导入装配体额外关节的位置，按URDF关节名索引；旋转为rad、移动为m，参数车模为空字典 |

暂停时停止调用会员算法；重载会重建 `Algorithm` 对象，其中的状态重新初始化。

## 输出

`step()` 返回一个字典：

| 字段 | 含义 |
| --- | --- |
| `left` | 左轮目标线速度，m/s，绝对值上限为配置的 `max_speed_m_s` |
| `right` | 右轮目标线速度，m/s，绝对值上限为配置的 `max_speed_m_s` |
| `gripper` | 可选，`grab` 夹取、`release` 释放 |
| `joints` | 可选，`{关节名: 目标位置}`，控制导入装配体的额外关节；旋转为rad、移动为m |

正轮速表示向前。底盘局部 +X 为车头，+Y 为左侧；世界坐标采用 ENU、Z 向上。桥接层用配置中 `response_s` 的一阶响应改变电机目标转速，默认 0.12 s；实际编码器继续反映轮地接触与碰撞影响。

夹爪参考点与抓取距离由 `gripper` 配置决定，默认位于车体中心前方 120 mm、允许距离小于 50 mm。该机构为简化取放模型。完整硬件字段见 [自定义小车](自定义小车.md)。

场景真值用于平台绘图和任务判定。会员接口提供图像与传感器数据，控制和识别程序由会员自行编写。

## 固件模式中的电脑视觉

“STM32固件”模式每6周期（192 ms）调用一次 `vision(image_bgr)`，返回字典中的 `uart_tx` 文本经所选USART送给MCU。消息格式由会员定义，原图来自同一个虚拟摄像头。该模式下电机读取MCU的PWM与方向输出，Python `step()` 不调用，详见 [固件执行](固件执行.md)。
