# 会员接口

编辑 `simulator/controllers/moonlight/member_algorithm.py` 中的 `Algorithm` 类，保存后在面板选择「会员算法」，点击「重载算法」与「开始运行」。空白模板返回零轮速。

## 图像

`vision(image_bgr)` 接收 BGR 通道顺序的 `numpy.ndarray`。尺寸由 `simulator/robot.json` 决定，默认 320×240，数组形状为 `(高, 宽, 3)`。每个控制周期调用一次；返回值通过 `sensors['vision']` 交给 `step()`。面板显示原始摄像头图像，识别程序由会员填写。

## 传感器

`step(sensors, dt)` 每个运行周期调用，`dt` 由 `step_ms` 决定，默认 0.032 秒。

| 字段 | 格式与单位 |
| --- | --- |
| `ir` | 按 `simulator/robot.json` 中红外位置列表的顺序排列；黑线接近 0，白地接近 1 |
| `sonar` | 按配置名称索引，默认 `front` / `left` / `right`；单位 m，量程由配置决定 |
| `encoder` | `left` / `right`，累计车轮转角 rad |
| `speed` | `left` / `right`，由编码器采样得到的轮缘速度 m/s |
| `carrying` | 仿真物理接触判定：物块已被两处爪指接触并稳定提离地面。该状态为练习辅助；实车需用自有传感器确认 |
| `vision` | 自己的 `vision()` 返回值 |
| `joints` | 夹爪及导入装配体额外关节的实测位置，按关节名索引；旋转为 rad、移动为 m。参数夹爪关节为 `gripper_left`、`gripper_right`、`gripper_lift`（如果启用） |

暂停时停止调用会员算法；重载会重建 `Algorithm` 对象，其中的状态重新初始化。

## 输出

`step()` 返回一个字典：

| 字段 | 含义 |
| --- | --- |
| `left` | 左轮目标线速度，m/s，绝对值上限为配置的 `max_speed_m_s` |
| `right` | 右轮目标线速度，m/s，绝对值上限为配置的 `max_speed_m_s` |
| `gripper` | 可选，`grab` 合拢、`release` 张开 |
| `gripper_lift` | 可选，`lift` 抬升、`lower` 降下；需有已配置的升降关节 |
| `joints` | 可选，`{关节名: 目标位置}`，直接控制各机械关节；旋转为 rad、移动为 m。若同周期也发了开合/升降命令，单关节目标优先 |

正轮速表示向前。底盘局部 +X 为车头，+Y 为左侧；世界坐标采用 ENU、Z 向上。桥接层用配置中 `response_s` 的一阶响应改变电机目标转速，默认 0.12 s；实际编码器继续反映轮地接触与碰撞影响。

开合与升降命令只设置电机目标。夹爪是否夹住取决于爪指轮廓、行程、推力、摩擦和物块姿态。可以同时控制开合和升降，也可以分开发出并观察关节反馈。完整硬件字段见 [自定义小车](自定义小车.md)。

场景真值用于平台绘图和任务判定。会员接口提供图像与传感器数据，控制和识别程序由会员自行编写。

## 固件模式中的电脑视觉

“STM32固件”模式每约 192 ms 仿真时间调用一次 `vision(image_bgr)`，返回字典中的 `uart_tx` 文本、字节或字节值列表经所选 USART 送给 MCU。消息格式由会员定义，原图来自同一个虚拟摄像头。该模式下电机读取 MCU 的 PWM 与方向输出，Python `step()` 不调用。详见 [固件执行](固件执行.md) 和 [调试与联调](调试与联调.md)。
