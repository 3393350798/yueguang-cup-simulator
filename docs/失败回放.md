# 失败回放

面板连接且仿真运行时，自动观察三类事件：碰到挡板、夹爪在合拢抬升状态下意外掉块、会员程序或固件执行报错。持续接触只在接触开始时记一次；主动张开夹爪放下物块不会触发掉块。片段一般覆盖事件前约 5 秒和后约 3 秒；短时间内的后续事件会在同一段里标出。

打开“失败回放”查看本机最近最多 4 段。点击事件可将位姿、物块位置、夹爪状态和波形游标定位到同一时刻，也可以逐个跳转事件或导出片段 JSON，在同一赛场版本的另一台电脑上打开。完整的“调试波形”录制仍可独立使用。

自动片段保存赛段、赛场版本、物块颜色、仿真周期、片段生成时间，以及位姿、传感器、轮速和夹爪等采样。片段不包含相机图像、串口字节、程序或固件内容、异常原文、项目路径或队伍组号。队员可以自行选择是否把导出的片段交给负责人。

面板关闭或未连接仿真时，不能捕获新的片段。若浏览器存储暂时不可用，当前页面仍可截取、回放和下载；刷新或关闭页面后，内存中的片段会丢失。事件发生后未满约 3 秒就重置或断开时，片段会标记为“提前结束”。事件时间按当前控制周期采样。

失败回放可协助定位仿真问题，但不会证明实板、无线串口或外部电脑程序有相同故障。
