# 分赛段练习

要测试起步摆位、物块摆放或灯光变化，请用独立的[赛场容差回归](赛场容差回归.md)。

在练习面板选择组号、物块颜色和赛段，再点击「摆位」。选择全程可恢复常规赛场起点。

| 赛段 | 起点 | 结果记录 |
| --- | --- | --- |
| 识别与抓放 | 物块东侧，车头朝西；标签仍在原比赛位置，需要自行观察 | 物块是否被稳定抬起、最大离地高度、夹持中掉落、最终是否在正确颜色与侧别的圈内、中心偏差 |
| 超声波通道 | 通道右口外，车头朝西 | 车体参考点是否由通道宽度内穿过左口、碰撞段数，以及固件报告的超声波触发次数 |
| 终点停车 | 停车区入口直线，车头面向终点 | 是否停稳、是否摆正，以及相对最近的停车朝向的角度偏差 |

手动或程序运行均可点击「记录本轮」，保存当时结果。选择「会员算法」或「STM32 固件」后，也可展开「多轮对照」，设置轮数和每轮仿真秒数；只想运行一次定时练习时，将轮数设为 1。每轮重载程序并按同一组号、颜色、起点和扰动设置复位，停稳后启动，达到设定时间后的第一个控制周期即记录。外部视觉程序如有本地状态，应自行按轮清空；串口和图像的外部时序不会自动重现。

点击「固定工况（6 轮）」会依次测试 2 组红／黄／蓝、1 组红／黄／蓝。奇偶组号各代表一种标签与放置侧；每轮沿用所选赛段、每轮秒数、当前车模、标定和扰动配置，并以同一起点和随机种子复位。界面显示当前工况与进度，普通「开始多轮」仍按你手动选择的组号与颜色重复。固定工况里某一轮程序异常会单独记为异常并继续；切换模式、摆位、暂停或断开场景时会停止自动测试，保留已经记录的结果。

结果按所选赛段列出第一个未通过的练习项，不适用的列显示「—」。如果当前浏览器仍保有该轮的碰撞、意外掉块、程序异常或达到时限但任务未完成的片段，可点击「查看本轮失败片段」直接回放。达到时限时没有已捕获的事件片段，才补录末尾约 5 秒。导入的对照报告不会关联其他轮次，导出的结果也不含片段。

可将各组运行导出为 JSON，再用「对照历史」导入上次记录。报告保留原始的单轮数据；比较成功率时请使用相同赛段、场地、设置和每轮时间。

### 本机练习历史

已记录的轮次会按单轮、多轮、固定工况或容差批次保存在浏览器。重新打开同一工程、并用**同一个浏览器和面板地址（含端口）**连接本工程后，展开「分赛段练习 → 本机练习历史」查看。未完成的批次只保留已经记下的轮次，不会自动续跑。点击对应轮次可打开保留的回放，或导出脱敏的[本轮求助包](求助包.md)。对照旧方案仍请用「导出结果」及时另存完整报告。

修完程序后，找到要验证的那一轮，选择原来的「会员算法」或「STM32 固件」模式，点击「按原条件复跑」。面板会使用当前程序，恢复该轮的完整组号、颜色、赛段、时限，以及适用的定时故障或容差参数。它会先核对场地、车模、仿真版本、实际开跑摆位和灯光；固件模式还会核对虚拟板卡外设配置。发现条件不符时会说明原因，车不会自动开跑。可以更换会员代码或固件镜像，无需恢复旧程序。

结束后，面板会列出前后结果和变化，并把这一轮单独留在本机历史；不会补跑其他工况，也不会计入六轮、普通多轮或容差通过率。手动结束、执行异常或缺少足够数据的旧记录只供查看。如果有外部串口输入，只展示两次结果；它不会重放外接电脑的状态、实时图像处理或串口内容。需要中止时，可点「停止本次复跑」或「暂停 / 停车」。关闭网页或断开连接后，已开跑的小车可能继续到时限；重新连接可点「暂停 / 停车」停止。普通结果 JSON 仍保留组号等常规字段，但没有本机复跑配方。对外求助时，请使用单轮脱敏求助包。

每个工程最多保留 60 轮，超过时整批清理最旧的结果；失败片段另有 24 MiB 上限，到上限时优先保留最近片段。可以主动清除本工程的历史和片段。工程副本、另一浏览器、另一端口的记录分别保存；不会自动导入旧版无法确认工程来源的片段。浏览器禁止存储时，当前页仍可记录、回放和下载，关闭页面不保留。

想验证程序在测距失效或虚拟串口异常时的表现，可设定[故障工况回归](故障工况回归.md)，用相同故障时间安排对照两个版本。

报告用于练习。超声波触发只说明固件发过触发信号，是否依靠超声波导航仍需按赛题确认；停车与放置的正式计分以赛事口径为准。
